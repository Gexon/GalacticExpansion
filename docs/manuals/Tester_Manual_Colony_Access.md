# Инструкция для тестера: как добраться до колонии GLEX

Для тестирования мода GalacticExpansion (GLEX) нужно иметь возможность быстро попасть к колонии Zirax и наблюдать её работу. Ниже — команды консоли и способы узнать координаты колонии. Тестер должен обладать правами **админа** или **GameMaster** (уровень 3+).

---

## 1. Получение прав админа / GameMaster

- **В игре (консоль `~`):**
  - `initadmin` — сделать себя первым администратором (если сервер ещё не имеет админов).
  - `setrole <PlayerId> <Role>` — выдать роль игроку (требует уровень 9; на сервере через telnet/консоль сервера).
- **На dedicated-сервере:** в `dedicated.yaml` или через telnet можно выдать себе роль с уровнем 3+ (GameMaster) или 6+ (Moderator) / 9 (Admin).

После этого команды `tt`, `gm`, `find` и т.п. будут доступны.

---

## 2. Узнать координаты колонии

Колонии хранятся в state мода. Координаты можно взять из файла или из логов.

### Вариант A: файл state.json

Путь к файлу состояния (на сервере):

```
[Корень игры]\Content\Mods\GalacticExpansion\state.json
```

Пример:  
`D:\SteamLibrary\steamapps\common\Empyrion - Galactic Survival\Content\Mods\GalacticExpansion\state.json`

В файле найдите секцию `"Colonies"`. У каждой колонии есть `"Position"` с полями `"X"`, `"Y"`, `"Z"` (в метрах):

```json
"Colonies": [
  {
    "Id": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
    "Playfield": "Akua",
    "Position": { "X": 1234.5, "Y": 102.3, "Z": -567.8 },
    ...
  }
]
```

Запомните **X, Y, Z** и **Playfield** (планета/playfield, например `Akua`).

### Вариант B: логи мода

При создании колонии мод пишет в лог строки вида:

- `ColonyTickModule: created initial colony <Id> on <Playfield> at (X, Y, Z)`
- `Creating new colony on '<Playfield>' at (X, Y, Z)`

Файлы логов: `[Корень игры]\Content\Mods\GalacticExpansion\logs\` (например `GLEX_2026-02-02_224701.log`). Поиск по слову `colony` или `created initial` покажет координаты и playfield.

## 3. Телепорт к колонии

Откройте консоль в игре клавишей **`~`** (тильда).

### Телепорт по координатам (X, Y, Z)

Сначала нужно находиться на том же **playfield**, что и колония (например, на планете Akua). Если вы на другой планете — сначала телепортируйтесь на планету (см. ниже).

Синтаксис:

```
tt <x> <y> <z>
```

Пример (колония на Akua в точке 1234, 102, -567):

```
tt 1234 102 -567
```

Игрок (и управляемый корабль, если есть) телепортируется в эту точку на текущем playfield.

### Телепорт на планету (playfield)

Чтобы перейти на нужную планету, где стоит колония:

```
tt <PlayfieldName>
```

Пример для Akua:

```
tt Akua
```

Если в имени есть пробелы — используйте кавычки, например: `tt "Planet Name"`.

### Телепорт к структуре по Entity ID

Если вы знаете **Entity ID** главной структуры колонии (поле `MainStructureId` в state.json или из команды `find`):

```
tt <EntityId>
```

Телепорт будет к этой сущности на текущем playfield.

### Поиск структуры по имени (узнать Entity ID)

На нужном playfield можно найти структуру и получить её ID:

```
find <часть имени структуры>
```

Дальше: `tt <EntityId>`.

## 4. Полезные команды для тестирования колонии

| Команда | Описание | Уровень |
|--------|----------|--------|
| `gm` или `godmode` | Вкл/выкл режим бога (не умирать, не тонуть и т.д.) | 3+ |
| `im` или `itemmenu` | Креативное меню предметов | 3+ |
| `di` | Доп. отладочная информация на экране | 6+? |
| `ents` | Список сущностей на текущем playfield | 3+ |
| `structlod` | Список структур с дистанцией от игрока | 3+ |
| `stats` | Статус текущего playfield | 3+ |

Рекомендуется включить **godmode** (`gm`) перед телепортом к колонии, чтобы не погибнуть от NPC или падения.

---

## 5. Типичный сценарий для тестера

1. Убедиться, что у вас права GameMaster (3+) или админа.
2. Включить godmode: `gm`.
3. Узнать playfield колонии (например, `Akua`) и координаты из `state.json` или логов.
4. Телепорт на планету: `tt Akua`.
5. Телепорт к точке колонии: `tt <X> <Y> <Z>` (подставить значения из state/логов).
6. Наблюдать за структурой колонии, NPC, поведением; при необходимости использовать `find`, `ents`, `structlod` для отладки.

---

## 6. Где лежат файлы (на сервере)

| Назначение | Путь |
|------------|------|
| Состояние (колонии, координаты) | `Content\Mods\GalacticExpansion\state.json` |
| Логи мода | `Content\Mods\GalacticExpansion\logs\` |
| Конфигурация | `Content\Mods\GalacticExpansion\Configuration.json` |

Корень игры — каталог установки Empyrion (например, в Steam: `steamapps\common\Empyrion - Galactic Survival`).
