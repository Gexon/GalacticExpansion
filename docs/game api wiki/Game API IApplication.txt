Application Mode

Enum for when you request process type of wherever the mod is running This is useful when restricting your mod so the parts that only work on certain processes are only loaded by those processes.

       ApplicationMode Mode { get; }

Example usage:

if(modApi.Application.Mode == ApplicationMode.DedicatedServer) { }

Chat Messages

To send chat messages to players, factions, serverwide You can set who you are chatting as too

       void SendChatMessage(MessageData chatMsgData);

For your mod to Receive chat messages: Event that is triggered when player, server, etc says something in chat. Works on Dedi process.

       event ChatMessageSentEventHandler ChatMessageSent;

To set up a listener so your mod knows when a player says something you need something like (do this in Init on Dedi process only).

               modApi.Application.ChatMessageSent += Application_ChatMessageSent;

and then you write the Method you just named Application_ChatMessageSent in order for the mod to be able to do anything with chat messages.
